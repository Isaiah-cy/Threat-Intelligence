# Threat Intelligence & Threat Hunting — Financial Services Sector

## 📌 Project Overview

This project demonstrates a structured **Threat Intelligence and Threat Hunting engagement** targeting the insurance and financial services sector, leveraging the **MITRE ATT&CK framework** and **SOCRadar.io** threat intelligence platform.

The engagement focused on analysing advanced persistent threat (APT) groups, identifying adversary tactics, techniques, and procedures (TTPs), and developing intelligence-led detection and threat hunting recommendations relevant to the financial services industry.

## 🎯 Objective

The project was designed to demonstrate practical threat intelligence capabilities through:

- Adversary research and profiling
- MITRE ATT&CK framework analysis
- Threat actor TTP identification
- Threat intelligence collection using SOCRadar.io
- ATT&CK Navigator technique mapping
- Threat hunting use case development
- Detection engineering recommendations
- Tactical, operational, and strategic intelligence reporting

## 🔍 Threat Actor Analysis

Seven threat actor groups were researched and profiled:

| Nation-State Actors | Financially Motivated Actors |
|---|---|
| APT41 | FIN7 / Carbanak |
| Lazarus Group | TA505 / Clop |
| Kimsuky | Scattered Spider / UNC3944 |
| Sandworm | |

The analysis examined their targeting patterns, attack techniques, operational behaviours, and potential impact on financial institutions and insurance organisations.

## 🛡️ MITRE ATT&CK Analysis

Using **MITRE ATT&CK Navigator**, individual technique layers were developed for each threat actor, followed by a composite overlap layer.

The analysis revealed that **12 of 15 ATT&CK tactic categories were shared by five or more of the seven profiled actors**.

This provided a basis for prioritising detection opportunities and developing threat hunting strategies against commonly observed adversary behaviours.
